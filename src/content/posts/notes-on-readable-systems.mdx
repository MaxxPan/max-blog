Readable systems do not require every file to be small. They require the important choices to be discoverable.

<aside>
  A good rule of thumb: a new contributor should be able to find the entry point, data shape, and failure mode without reading the whole project.
</aside>

For personal projects, this usually means fewer abstractions, sharper names, and a README that explains how work actually happens.
